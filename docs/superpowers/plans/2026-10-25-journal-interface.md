# 窥天录界面重做 Implementation Plan

**Goal:** 将现有四页见闻录重做为清晰、可操作、适配小窗口的墨金卷册。

**Architecture:** 复用 3.8.3 的玩家知识与网络协议。纯 Java 布局模型负责几何与命中，客户端 Screen 负责原生绘制和控件；宽屏三栏、小屏列表与正文切换，不缩放整屏。

**Tech Stack:** Minecraft 1.21.1、NeoForge 21.1、Java 21、现有离线构建。

## 约束
- 保留观象、察局、藏识、行藏和服务端权限边界；不添加演示事件到玩家存档。
- 不恢复商城、积分、百世书，不升级加载器，不安装进真实实例。
- 不启用背景模糊、不平铺带边框的面板、不对整屏做小数缩放。
- 用户已认可前述窥天录设计并要求实施，本轮不重复征求设计许可。

## 步骤
- [x] 为 240×180 至 1920×1080 的布局、区域命中和滚动边界编写失败用例。
- [x] 实现纯布局模型，保证所有可操作区域留在窗口内。
- [x] 重做原生 Screen：墨卷边饰、双行列表、来源标签、分段详情、真实空状态。
- [x] 接入搜索、收藏筛选、页签、返回、关闭、键盘与独立滚动，复用现有服务端动作。
- [x] 验证数据更新/切页不会保留不可见条目的正文；小窗显示完整按钮。
- [x] 离线测试、编译、构建新补丁版本；保留旧 JAR，记录实机验证边界。
