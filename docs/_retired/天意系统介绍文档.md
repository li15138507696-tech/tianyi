# 蛊真人·天意 —— 玩家向说明

> 版本：**tianyi-2.10.0** ｜ 环境：Minecraft 1.21.1 · NeoForge 21.1.x · Java 21
> 前置：蛊真人本体（`guzhenren`）
> 定位：把「天命」「道途」「神之商店」三个附属合成一个模组，并新增一套「天意」系统

---

## 〇、版本变更

### 1.0.9 改了什么（修致命加载错误）

**1.0.8 及以前根本装不上**：`tianyi.mixins.json` 的 `"package"` 写成了根包
`net.guzhenren.tianyi`，Mixin 把整个包（含 `@Mod` 主类与 94 个普通类）当成 mixin 命名空间，
于是报 `IllegalClassLoadError: TianyiMod is in a defined mixin package`，模组容器初始化 FATAL。
崩溃报告末尾那句 RuOK `Config ... has not been registered` 是**连带假象**（容器初始化被中止，
RuOK 自己的配置注册没跑到）。

修法：拆成 `tianyi.open.mixins.json`（`…open.mixin`，3 个）与
`tianyi.shop.mixins.json`（`…shop.mixin`，2 个），`package` 精确到只装 mixin 的包。
新增 `audit_mixins.py` 专门守这条（包内不得有普通类、不得有 `@Mod` 混入）。

### 1.0.8 改了什么

1. **自定义模型接口**：`config/tianyi-ai-providers.json` 里可以定义**任意** HTTP 模型服务
   （请求头、请求体模板、回复路径全可配），首次运行自动生成 OpenAI / Anthropic / Ollama 三份示例。
2. 三条命令：`/tianyi ai providers`（列表）、`/tianyi ai provider <id>`（选用）、
   `/tianyi ai reload`（改完 json 热加载）。
3. `ai.mode` 新增 `provider`；`auto` 优先级变为
   Numen → 玩家自己的 key → 自定义接口 → DSH 本体 → 服主兜底 → 本地模板。

### 1.0.7 改了什么

1. **新增「DSH 本体凭据」后端**：本机跑着 DeepSeek Harness 时，模组直接复用它的 provider
   凭据出题，**玩家零配置**。`ai.mode` 新增 `dsh`；`auto` 优先级变为
   Numen → 玩家自己的 key → DSH 本体 → 服主兜底 → 本地模板。
2. 面板「降谕」页多一个 `DSH本体` 标签；`/tianyi ai status` 会显示凭据来源与 DSH 状态。

### 1.0.6 改了什么

1. **接入 Numen**（LLM 同伴）：装了就用它的模型直接降谕，玩家不必再自己填 key；
   AI 通过官方扩展点 `ToolRegistry` 调用 `tianyi_destine` 下旨，其状态由
   `contributeState` 注入。**没装 Numen 自动退回**自建 HTTP（1.0.5 那套），再退回本地模板。
2. 奖励仍归服务端：工具参数里**没有**任何奖励字段，难度服务端推导、奖励查表。
3. 面板「降谕」页会显示当前后端（`Numen` / `自建AI` / `本地模板`）。

### 1.0.5 改了什么

1. **新增「AI 降谕」**：玩家配自己的 AI（OpenAI 兼容），让它读你的真实状态出一道试炼。
   AI 只能填受限模板，**奖励由服务端按难度算**。每日可祈问 1 次，失败自动退回本地模板。
2. 详见 [AI 降谕设计](AI降谕设计.md)；配置与命令见文末附录。

### 1.0.4 改了什么

1. **主线从 9 章缩到 5 章** —— 本体境界只到五转，六转以后的章节永远解锁不了，是凭空多出来的。
   现在 **25 条主线（5 章 × 5）**：一转～五转，每章 5 条，合计 420 天机点。
2. **章与妖兽阶严格对上**：第 N 章（需 N 转）主考「N 阶以上妖兽」，另配一条「N−1 阶以上」清剿。

### 1.0.3 改了什么

1. **妖兽分级换成「兽王五阶」** —— 1.0.2 按最大生命分档是错的（魂兽与万兽王同为 1000 血、
   木魅树精与兽皇同为 760 血、炼王 1000 血而炼道修士 300 血），已废弃。
   现在按本体唯一成体系的分级：**妖兽/魂兽 → 百兽王 → 千兽王 → 万兽王 → 兽皇**。
2. **修士暂不参与试炼**（蛊修/人物 NPC 没有等级体系）。
3. 主线标准改成「斩杀 N 只 K 阶以上妖兽」，高阶只要求 1–2 只（每阶本体只有 2 个实体）。

### 1.0.2 改了什么

1. **主线试炼全部换成打本体妖兽** —— 原来杀僵尸、拾煤炭、合火把，现在考本体的妖兽。
2. **转数按血量判定**（1.0.3 已废弃，见上）。

### 1.0.1 改了什么

1. **开窍过程完全交还本体**：右键希望蛊走本体原流程（随机空窍资质 1–10 → 本体资质面板 →
   关闭时结算资质）。本模组不再拦截 `use`、不再替换本体面板、不再自动弹自己的界面。
2. **新增「天机阁」**：用**天机点**购买「天命」的**词条**（137 条）与**凡体体质**（20 种），
   共 157 件。**十绝体与机缘不上架**（它们直接覆写本体开局资质字段，中途买会与本体开窍结算打架）。
3. 价格**按效果强度**折算，不是按品质一刀切，见 [天机阁价目表](天机阁价目表.md)。

## 一、一句话

**打怪、走路、打坐都在替天意干活；干完活领天机点；天机点能换元石、能摇命、能签到。**

三个旧附属的功能一个没少：

| 原附属 | 现在在哪 | 你还能做什么 |
|---|---|---|
| **天命**（tianfu） | 面板 → 「天赋」 | 开局难度选点、买体质/词条/机缘、最终确认、转世重开 |
| **道途**（daotu） | 面板 → 「道途」 | 历练三路攒满 → 5 选 1 → 永久成长；主修流派 |
| **神之商店**（shenshang） | 面板 → 「商店」 | 蛊虫/蛊材/蛊方/原版买卖、搜索、限购、元老蛊钱包 |
| **天机阁**（新） | 面板 → 「天机阁」 | 用天机点买天命词条与凡体体质（不含十绝体/机缘） |

> **开窍还是本体的那一套**：希望蛊 → 随机空窍资质 → 本体资质面板。本模组只在你开完窍之后
> 说一句「按 J 看看」。

## 四、天意试炼

### 4.1 三种试炼

| 种类 | 条数 | 重置 | 解锁 |
|---|---|---|---|
| **主线** | 25（5 章 × 5） | 不重置（本世一遍） | 第 N 章要 **N 转**（本体只到五转） |
| **日常** | 6 | 每游戏日 | 一转起 |
| **周常** | 3 | 每 7 游戏日 | 一转起 |

### 4.2 目标类型（1.0.3：本体妖兽，兽王五阶）

主线**全部打本体妖兽**，不再考「杀僵尸 / 拾煤炭 / 合火把」：

| 目标 | 说明 |
|---|---|
| **猎杀本体妖兽**（主） | `斩杀 N 只 K 阶以上妖兽` —— 阶数按**兽王名号**，不看血量 |
| 修炼进度 | 读本体 `gushi_xiulian_jindu` 的增量 |
| 累计在线分钟 | — |
| 进入维度 | 下界 / 末地 |
| 拾取 / 达到转数 | 只保留少量做调剂 |

**妖兽五阶**（本体唯一成体系的妖兽分级，写在实体名里，共两族十只）：

| 阶 | 名号 | 本体实体 | 备注 |
|---|---|---|---|
| 1 | 妖兽 / 魂兽 | `hunshou_1`、`mumeishujing_1` | 其余无称号的本体妖兽也算 1 阶 |
| 2 | 百兽王 | `hunshou_2`、`mumeishujing_2` | |
| 3 | 千兽王 | `hunshou_3`、`mumeishujing_3` | |
| 4 | 万兽王 | `hunshou_4`、`mumeishujing_4` | |
| 5 | 兽皇 | `hunshou`、`mumeishujing_5` | 最高阶 |

- **「K 阶以上」含更高阶**：杀兽皇也算「二阶以上」，不会因为打了更强的反而不算数。
- **章与阶一一对应**：一转章打一阶（妖兽/魂兽）、二转章打二阶（百兽王）……五转章打五阶（兽皇）。
- **每阶只有 2 个实体**，所以高阶级试炼只要 1–3 只（五转章的「兽皇 ×3」就是终章硬指标）。
- **每阶只有 2 个实体**，所以高阶级试炼只要 1–2 只（兽皇 ×2 就是终章硬指标）。
- **不用血量**：1.0.2 那套按 `MAX_HEALTH` 分档是错的 —— 魂兽与万兽王都是 1000 血，
  木魅树精与木魅·兽皇都是 760 血，炼王 1000 血而炼道修士 300 血，血量与阶位无关。
- **修士暂不参与**：蛊修 / 人物 NPC 没有等级体系（名字里只有 4 条带「(N转)」），按口径先不进试炼。
- 特效（`texiao`）与尸体（`shiti`）实体不计入。
- 完整 36 条见 [天意试炼一览](天意试炼一览.md)。

### 4.3 奖励

主线 8–30 点（越后越高，五章合计 420 点）、日常 5–6 点（32 点/天）、周常 15 点（45 点/周）。**达成后要回面板点「领取」**，不会自动进账。

> 为什么要点一下：领奖是服务端权威校验（重新核对「已达成且未领」），点这一下就是那次校验。

## 五、天机点与兑换

- **天机点**是软通货，只能从试炼 / 签到 / 摇命里来。
- **兑换**：1 天机点 = **100 元石**，每日上限 **50 点**。
- **单向**：元石换不回天机点。原因很直接 —— 元石能从商店刷，若能反兑就是无限套利。
- 兑换写的是本体 `yuanshishuliang`，和商店钱包（元老蛊）完全一致，没有第二套货币。

## 七、宿命蛊 · 摇命

- 一次 **20 天机点**；**每日首抽免费**。
- 结果三档：
  | 档位 | 概率 | 内容 |
  |---|---|---|
  | 命不在此 | 30% | 无事发生（保底进度 +1） |
  | 小奖 | 40% | 天机点 +10 或 元石 +1000 |
  | 大奖 | 30% | 天机点 +40 / 元石 +5000 / 总道痕 +100 |
- **保底**：连续 10 次没出大奖，下一次强制大奖并清零。

## 八、天机阁（用天机点买天命）

面板底栏点「天机阁」，右栏变成商品列表（按价格从低到高）：

```
[词条] 筋骨强健  玄   80点    [买]
[词条] 暴击如神  天 1070点    [买]
[体质] 断岳剑心体 凡体 1620点  [买]
```

- **卖什么**：天命的**词条** 137 条（内置 22 + 扩展 125，除去 10 条负品质）+ **凡体体质** 20 种，
  共 **157 件**。
- **不卖什么**：
  - **十绝体 / 机缘** —— 它们直接改写本体的 `kongqiao / tizhi / 最大真元 / 气运上限`，
    是开局资质的领地，中途用天机点买会和本体开窍结算打架；
  - **负品质词条** 10 条 —— 天命里它们是「花点数买罪受、返还点数」的机制，
    花天机点买负面效果没有意义。
- **前置**：需要先在本世「天赋」页完成**最终确认**。天命的设计是「先确认、后生效」，
  天机阁买的东西要求在同一套生效门禁下，否则会出现「买了没效果」。
- **体质唯一**：本体开窍可能已经给了你体质（`tizhi ≠ 0`），那体质就不能再买；
  已买过体质同理。
- **价格**：按词条的**效果强度**折算，不是品质一刀切 —— 同为「极」，效果多的更贵
  （内置 22 条的效果写死在代码里、没有数据表，改用「原天赋点成本」当强度信号）。
  完整价目见 [天机阁价目表](天机阁价目表.md)（脚本自动生成，会随词条表变化重算）。

| 品质 | 条数 | 价格区间 | 均价 |
|---|---|---|---|
| 极 | 3 | 1910 – 2250 | 2046 |
| 神 | 13 | 360 – 1440 | 979 |
| 天 | 24 | 230 – 1070 | 455 |
| 地 | 27 | 130 – 490 | 259 |
| 玄 | 37 | 80 – 310 | 164 |
| 黄 | 33 | 80 – 220 | 94 |

体质（20 种凡体）统一 **1620 点**。

> 参照系：主线一条 8–30 点、**五章合计 420 点**；日常 32 点/天、周常 45 点/周、签到 5–22 点/天、摇命 0–40 点。
> 也就是说**一条「极」≈ 半个主线（五章 420 点）**，通常要跨世攒；天机阁是「后期补票」，不是开局捷径。

## 十一、常见问题

**Q：按 J 没反应？**
还没开窍。用**希望蛊**开窍后才会激活。

**Q：试炼进度不动？**
主线要对应转数才解锁（第 5 章要 5 转）；日常/周常在游戏日切换时重置，进度会归零重来。

**Q：摇命一直「命不在此」？**
保底 10 次，看左栏「保底 N/10」。

**Q：兑换按钮点了没反应？**
每日额度（50 点）用完，或者天机点不够。

**Q：商店打不开？**
面板底栏点「商店」；或去按键绑定里给「神之商店」绑一个键。

**Q：和别的附属冲突吗？**
旧三个 jar 不能同装。其它附属（魂道、兼修、六合一、运道…）按原有软依赖关系工作。

## 附、AI 降谕（可选，1.0.6）

让 **AI** 读你的转数、真元、寿元、各阶妖兽战绩，给你出一道合身的试炼。**两条路，按装了什么自动选**：

### 路一：装了 Numen（推荐，不用自己填 key）

装了 [Numen](https://modrinth.com/mod/numen)（LLM 同伴）就直接跟你的同伴说话：

```
你：给我降一道试炼
同伴：……（它读得到你的转数/寿元/妖兽战绩，然后调用 tianyi_destine）
```

也可以按 **J** → 底栏 **「降谕」** → **「祈问天意」**，我们给同伴发一条急信让它立刻降谕。

- 模型与 key 用的是 **Numen 自己的配置**，你不用在这边填任何东西。
- 同伴只负责「说什么」；**打什么、给多少分还是这边说了算**。

### 路二：没装 Numen（自建 HTTP，用自己的 key）

```
/tianyi ai setkey sk-你的key
/tianyi ai setmodel deepseek-chat          # 可选，默认就是它
/tianyi ai setendpoint https://api.deepseek.com/chat/completions   # 可选
```

然后按 **J** → 底栏 **「降谕」** → **「祈问天意」**。

### 两条路共同的规矩

- 每日 **1 次**；手上最多 3 道未完成的谕令；谕令 3 个游戏日后过期。
- **AI 决定不了奖励**：它只填「打什么、多少」，难度由服务端按目标算，奖励查表（10/18/28/40/55）。
- AI 不可用（没 Numen 也没配 key、超时、胡说八道）→ 自动降下**本地模板**谕令，不扣次数，不会让你空手。
- 自建 HTTP 的 key 只存在服务端玩家数据里，**不会发给客户端**；命令回显只有掩码。服主可配 `ai.serverKey` 全服兜底。
- 本地模型（Ollama / LM Studio）走 HTTP 路，endpoint 填 `http://localhost:11434/v1/chat/completions`。
