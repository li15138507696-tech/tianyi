## 一、这是什么

在原著里，天意不是一个人，不是一段对话，也不发任务。它是那种「什么都没说，但你事后发现事情都是冲着某个人去的」的东西。

这个模组做的就是这件事：

- 它**在世界背后持续判断**——谁在逆天、谁在崛起、谁值得扶持、谁需要压一压；
- 它的动作**只以世界现象出现**——地上长出蛊材、妖兽被赶过来、有人上门、天变了；
- 它**不给你面板**去显示自己的评分、你的威胁度、它的布局名单。

一句话：**你能感觉到它，但你查不到它。**

### 它不是什么

| 不是 | 说明 |
|---|---|
| 不是面板模组 | 没有「天意好感度」「威胁评分」「干预清单」，也没有 J 键之外的世界信息界面 |
| 不是任务系统 | 不发任务、不给奖励弹窗、不结算积分 |
| 不是签到/商城/词条 | 3.0.0 起天机积分、签到、摇命、永久词条商城、命契商店、百世书收益**全部退场**，不再恢复 |
| 不是升仙系统 | 本模组不新增升仙玩法 |
| 不是善恶奖惩机 | 道德、气运**真的参与**判断，但天意不按「好人给糖、坏人挨打」办事 |

## 二、你会在游戏里遇到什么

天意的动作全部落在世界本身。下面这些是**已经实现的**现象。

### 1. 野外的蛊材产地

扶持某个人时，天意不会把东西塞进背包，而是**在离他 24~56 格的地表开一处产地**。

- 出产的是本体真实的未炼化蛊 / 元老蛊 / 蛊方；
- 产地有**储量、每日恢复、上限**；走近（24 格内）才会出货，一轮最多 2 件；
- **第一个来采的人成为归属人**，别人再来采会被记为掠夺；
- 采空且不恢复 → 变成「荒」；被天意针对时储量和恢复都会被压。

### 2. 货会「送到手上」

产地有主、人不在跟前时，货走**批运输送**，约 2400 刻后落到脚下。
收货人不在线 → 货**退回产地**，不会凭空消失。

> 目前看不到「车队实体」，只看到东西到账。这是已知局限。

### 3. 妖兽被赶过来

压制时天意会从**最近的兽群**赶 3~7 只本体妖兽过来（魂兽 / 木魅树精等）。

关键是 **赶一只少一只**：兽群有真实种群，打光了就崩溃，要等 5 个游戏日、且栖息地还过得去，才会有邻群迁入 **1 只**。
所以**不会出现「在你身边无限刷怪」**。

### 4. 有人上门

压制**道德高或威胁大**的人时，天意优先「借人施劫」，而不是直接降灾：

- 先酝酿 6000 刻（5 分钟），三步走「流言 → 聚人 → 上门」；
- 酝酿期你**跑出 512 格、换维度、或进入盲区**，这次布局直接作废；
- 表现：1~2 名本体修士 NPC 出现在附近、以你为目标、1 游戏日后离开。

> 他们是否真会打起来取决于本体 AI，**这一点没有实机验证过**。

### 5. 灾劫

四等：**地灾 / 天劫 / 浩劫 / 万劫**。四阶段：**酝酿 → 显形 → 判定 → 余波**。

- 天劫以上会**变天**；显形有**闪电**，浩劫以上带**妖兽潮**与烟雾；
- 判定按你的转数、道痕算防御，伤害有上限；渡过给**天道道痕**，失败扣道痕与寿元（**不抹杀**）；
- 有 45% 的针对性硬上限 —— **准备充分就能活**。

### 6. 野外的寿蛊

每 30 游戏日，在离玩家 32~96 格的地表成一颗寿蛊；歉收期可能**一颗都不成**。
只产出本体 `NpcStock` 认的寿蛊 ID，**不塞背包、不动 NPC 补货**。

### 7. 看穿了会「打雷」

捡走某个**诱饵产地**的第一批货 → 局部雷雨 + 一记偏移 8 格的闪电（不会劈死）。
这是「道破即震怒」的最小实现。

## 三、《窥天录》——玩家自己的册子

这是模组里唯一的界面，**只记录你有依据知道的事**。

- **按键 J**（可在「按键设置 → 天意」改绑），Esc 或再按 J 关闭；
- 多人游戏打开**不暂停**世界。

### 四页

| 页 | 内容 | 数据来源 |
|---|---|---|
| **观象** | 最近发生的异常 | 亲手拾得蛊材、自己名下产地出货、诱饵雷雨、人劫 NPC 出现、自己渡过的灾劫 |
| **察局** | 把见闻关联成疑局 | 你手动「记入疑局」，结论按证据数/来源数/存疑标记算成**孤证 / 相互印证 / 存在矛盾 / 尚无定论** |
| **藏识** | 经得起验证的认识 | 亲手打过的兽类、炼制**尝试**（结果一律「未核实」） |
| **行藏** | 自己留下的痕迹 | 有载体看着的当众击杀 |

### 操作

| 操作 | 作用 |
|---|---|
| **J** | 开 / 关（输入查阅文字时，J 只当普通字母） |
| **Esc** 或右上角 × | 关闭 |
| 输入框 | 按当前卷的标题、正文、疑局名、来源查找；**Ctrl+F** 聚焦 |
| 「收藏」 | 只看已收藏条目 |
| 滚轮 / 拖动滚动条 | 列表与正文**各自独立**滚动 |
| 方向键 / Enter / PageUp·PageDown | 选条目 / 小窗展开 / 翻页 |

- **宽窗口**：目录 + 列表 + 正文三栏同时显示；
- **小窗口**：点条目进入正文，用「返回卷目」回列表（分卷式，不压缩整块面板）。

### 三条硬规矩

1. **只写你有依据知道的**：服务端按你的档案筛选后才下发，世界总账根本不会发到客户端；
2. **不虚构**：没有可靠来源的事件不生成；没数据就显示「尚无相关见闻」，**不会写成"此地安全"**；
3. **标注只是标注**：收藏 / 存疑 / 记入疑局**只改你自己的笔记**，不触发雷电、不算识破、不给奖励。

### 题名会变

- 默认叫 **见闻录**；
- 亲见 ≥ **3** 条、且至少一条已记入疑局后，才改叫 **窥天录**，并显示副题
  「所见未必为真，所得未必为福」（界面原创文案）。

### 界面风格

墨底 `#1B1D1B`、骨白正文 `#D8D0BA`、旧金结构 `#A88A48`、暗朱表示矛盾/损失 `#9F4A3D`、灰青表示陈旧/未核实 `#8B9C9B`。
横向旧卷册：左目录 / 中列表 / 右正文。陈旧条目会**用文字写「久未核实」**，不只靠颜色。

## 四、天意是怎么判断的（设计者视角）

```
感知：载体触达范围内、且未被遮蔽，才"看得见"
  ↓
判断：威胁 = 实力/资源/逆天行为/成长速度/情报置信度（看不见的按旧情报算，没情报就不参与）
  ↓
布局：机缘（可被截取）、诱饵、人劫（借人之手）
  ↓
扶持 / 压制 / 观测 / 放任  ← 姿态每轮按局势刷新，压过的人变弱了会转回扶持
  ↓
灾劫：四等四阶段，有针对性上限
```

**道德与气运怎么参与**

- 道德 → 影响**社会代价**与人劫渠道选择（道德高的人更容易"借人之口"而非直接降灾）；
- 气运 → 影响**机缘酝酿时长**与有边界的遭际；
- 两者都**不会**被换算成「天意对你的好感」。

**载体与反制**

天意的寄存与传播靠「载体」（天道道痕、地脉、修行者、仙元石、宿命蛊、区域）。
载体有**统一状态机**：活跃 / 沉睡 / 枯竭 / 已清除 / 恢复中。

原著里的反制手段逐环生效：**暗渡、神不知、天消意散、炼道清除、天机、天外之魔** ——
它们分别影响「寄存 / 传播 / 清除 / 观测 / 宿命绑定」的不同环节，不是简单免疫。

> 现状：反制状态机是完整的，但目前**只能通过管理员命令挂上**，还没接到本体的具体蛊虫/器物使用上。所以正常玩法里玩家暂时用不到——这条如实记录在技术边界文档里。

## 七、常见问题

**Q：玩了一小时，什么都没发生？**
这不是随机事件模组。天意的动作需要条件：载体覆盖到你所在区域、你产生了逆天行为、或者局势上你成了值得扶持/压制的对象。**安静本身就是一种状态**——它可能还没"看见"你。

**Q：按 J 打开是空的？**
正常。所有条目都来自你的真实经历。去野外捡一件 `guzhenren` 的蛊材，再打开就会多一条「拾得…」。

**Q：为什么没有好感度/进度条？**
设计如此。天意不对外暴露自己的判断。你只能通过世界现象反推。

**Q：灾劫会不会必死？**
不会。有 45% 针对性上限，且失败只是扣道痕与寿元，不抹杀。准备充分是能过的。

**Q：面板里的「存疑」会让天意注意到我吗？**
不会。那只是你自己的笔记，不产生任何世界效果。

### 未验证 / 未完成（如实列出）

1. **没有做过完整的实机验收。** 面板渲染、事件触发频率、NPC 是否真会打起来，都还需要在真实游戏里跑。
   3.8.4 的界面重做也只有离线布局检查与预览图，**没有真人操作验收**。
2. **炼蛊产物无法确认**：本体不暴露「这次炼出了什么」，背包差分又不能单独作为证据，所以册子里只记「炼制尝试：结果未核实」。
3. **身份证据只有两个来源**（当众击杀、炼蛊痕迹），证词/持有物/关系线索未接。
4. **反制只能靠命令挂**（见第四节）。
5. **布局与灾劫的运行期状态不持久化**（机缘已持久化，重启不丢）。
6. **B09 追捕**：目前只能下移动命令，尚未接入本体「对玩家通缉」的接口，因此不视为已实现追捕。
7. 以下能力**完全没做**：侵蚀并制造仙元石、催动他人仙蛊、真正的福地洞天维度、升仙对话窗口、万劫地貌改写。
