## 一、这是什么

旧版天意指「面板 + 天机积分 + 签到 + 摇命 + 商城」。3.0.0 把这些**全部退场**，
改成原著里的那个东西：**世界背后的意志**。

它在后台做四件事，玩家看不到它本身，只看到它造成的结果：

| 它做什么 | 玩家看到什么 | 玩家看不到什么 |
|---|---|---|
| 感知（谁在哪、多强、干了什么） | 载体重叠的区域里它「知道」你 | 没有「天意注视度」、没有雷达 |
| 判断（失衡、威胁、棋子价值） | 世界对强者的态度变了 | 没有威胁评分、没有干预清单 |
| 布局（酝酿、执行、失败重判） | 兽群、上门的人、被搅乱的资源 | 没有任务面板、没有「布局进度」 |
| 扶持 / 压制 | 野地里的蛊材、传承蛊方、灾劫 | 没有「奖励到账」、没有好感度 |

3.0.0 移除了旧积分与商城面板。3.8 起，J 键打开的是玩家自己的《见闻录》/《窥天录》，
只整理已获得的见闻与依据，不公开天意后台布局；3.8.4 重做墨金卷册、搜索、筛选与小窗阅读。

### 天意 ≠ 天道 ≠ 宿命蛊 ≠ 星宿意志

考据的两条分界句决定了实现必须分四层：

> 「天道大公无私，对方源并无恶意，改变环境都是自然演化而已。但天意却非如此。」
> 「天意由天道演变而生，更加灵活机智。」——7《迷雾中的方源》

- **天道规律**：原版 Minecraft 与世界生成的自然演化，本模组不注入、不代理。
- **天意（主动干预）**：`WillCore`，有指向性但**无善恶、无情绪**。
- **宿命蛊**：`Destiny.DestinyGu`，世界唯一状态机。
- **星宿意志**：`Destiny.StarWill`，人的意志寄生在天意运转里，**会与天意争**。

### 道德与气运的正确用法

考据明确：

> 「天意，从不是看我们不顺眼，来为难我们。也从不会看我们可怜，来帮助我们。」——2《一切都是天意》

所以实现里：

- **道德不进入威胁评分**。它只影响「社会代价」（`Assessment.Actor.socialTrust`）与
  「人劫可利用性」—— 道德高的人社会信任高，天意动他的**代价**更大，
  于是更倾向「借人施劫」（`WillCore.chooseSuppressChannel` 选 `RUMOR`）而不是直接降灾。
  但**道德不构成豁免**：`Assessment.shouldSuppressDespiteMorality` 在失衡+威胁够高时照样返回 true。
- **气运不进入威胁与压制**。它只影响机缘能否被他碰到（`Opportunity.Forge` 里按
  `effectiveLuck()` 缩短/延长酝酿期）。**机缘多 ≠ 气运好 ≠ 天意偏爱** —— 机缘本身可能是诱饵。
- **气运不假设 0–100**：`qiyun_shangxian <= 0` 时气运不参与任何走向（`effectiveLuck() == 0`）；
  负气运不算「超常」，只是「凶」；超过 100 不压回区间，只标记 `luckAnomalous()`。

## 三、机制怎么跑

### 3.1 感知：天意有知识边界

`will/Knowledge` 的 `Store` 里每条情报都带**来源、时间、位置、可信度、渠道**：

| 来源 | 可信度 | 含义 |
|---|---|---|
| `SELF_SPREAD` | 1.00 | 天意自身分布在已加载区块里看到 |
| `CONTACT` | 0.90 | 实体与天意载体/造物接触 |
| `CARRIER` | 0.80 | 经载体回报 |
| `EVENT` | 0.75 | 世界事件被记录 |
| `RUMOR` | 0.35 | 传闻，会变形 |
| `INFERRED` | 0.20 | **推断**（不能当观测写入，`observe` 会拒绝） |

- **后台能读到 ≠ 天意知道**：`Observation.observe` 对每个玩家先算载体触达
  `carriers.reachAt(dim, pos)`，`<= 0.15` 就**一条情报都不写**。
- **遮蔽即真盲区**：`Store.cover(id, now, ticks, cause)` 之后 `latest()` 返回空，
  `track()` 返回 `live=false, positionStale=true, pos=NO_POS` —— 只剩旧情报的模糊推断。
- **旧情报会腐烂**：超过 `FACT_SOFT_TTL`（1 游戏日）可信度线性衰减，
  超过 `FACT_HARD_TTL`（8 游戏日）直接清除。

### 3.2 判断：决策器按三件事行动

`WillCore.decide` 每 200 刻跑一轮（`WillConfig.DECISION_PERIOD`），只看 16 个参与者
（`DECISION_BATCH`），不扫全世界：

1. **维持平衡**：份额超过 `IMBALANCE_SHARE`(0.38) 且超出死区 → 压制（不看善恶）。
2. **制约威胁**：`threat = 份额 + 增长趋势 + 天意<b>实际知道</b>的逆天行为`，再乘确定性折扣。
   情报置信度 `< 0.35` 时**只派观测，不动手**。
3. **利用棋子**：`utility = 可撬动 × 社会位置 × 资源`，与善恶无关 —— 魔头是好刀，高德者是好旗。

**防无限叠加**：同一目标同一手段最多 `MAX_SAME_ACTION`(2) 次；布局失败后
`PLOY_FAIL_COOLDOWN`(3 游戏日) 冷却，期间不对同一目标重开同类布局。
姿态可以翻转（`switchPosture`）：玩家变强就从「扶持」转「压制」，反之亦然。

### 3.3 扶持：世界里真的有东西

**不往背包塞物品**（`audit_will.py` 严格禁止 `addItem`/`setItem`）。扶持只有两条落地方式：

| 渠道 | 落地 | 出处（`origin`） |
|---|---|---|
| `RESOURCE` | 地表生成 `ItemEntity`（未炼化蛊 / 元老蛊，id 从本体 `tags/item/dushi.json` 与 `yuanshi.json` 核对） | 「野外蛊材在 zhongzhou 自然成熟」 |
| `HERITAGE` | 地表生成蛊方（`tags/item/gufang.json`） | 「某位蛊师遗留的蛊方在 donghai 显形」 |

- 生成点距目标 24–56 格（`WorldExec.MIN/MAX_SPAWN_DISTANCE`），**不刷在脸上**。
- **谁先到就是谁的**：`Opportunity.Offer.claim(claimant, now)` 对任何主体开放，
  `intercepted()` 记录「被非预期对象截取」。
- 少数机会是**诱饵**（`bait`），占比受 `BAIT_RATIO_CAP`(0.34) 约束；捡走诱饵会触发
  「道破即震怒」的局部雷雨（原著 1 章）。

### 3.4 压制：四条真实渠道

| 渠道 | 落地方式 |
|---|---|
| `BEAST` | 目标周围 24–56 格生成 3–7 只本体一阶妖兽（`guzhenren:hunshou_1` / `mumeishujing_1`），走自然消失，总上限 `BEAST_DRIVE_MAX`(24) |
| `RUMOR` | 人劫：生成 1–2 名本体修士（`guzhenren:renwunpc_3/5`），`setTarget` 后限时 `RENJIE_LIFETIME`(1 游戏日) 由 `WillServer` 收回 —— **不是永久仇恨傀儡** |
| `FACTION` | 嫁祸：`FactionBrain.blame(level, territory, b, a)`，用 `guzhenren_library` 的真实势力系统留下由头，冲突由本体 AI 自己决定是否升级 |
| `CALAMITY` | 满足条件才开灾劫（见 §3.5） |
| `RESOURCE` | 仙窍资源点被打散（`degradeResourcePoint`，按 55% 打散并损伤稳定性，留可调查痕迹） |

**玩家能破坏酝酿中的布局**：`Ploy.evaluate` 会因以下任一条件判失败 ——
目标进入盲区、失去情报、距离超过 `RENJIE_BREAK_DISTANCE`(512 格)、渠道丢失、超时、
执行者实力不敌（`executor-outmatched`，人劫会扑空而不是必死）。

### 3.5 灾劫：四等、四阶段、有收益

- **四等**：地灾（转数 0+）/ 天劫（3+）/ 浩劫（5+）/ 万劫（6+）。
- **四阶段**：`GESTATING` 酝酿 → `MANIFEST` 显形 → `CLIMAX` 判定 → `AFTERMATH` 余波。
  每个阶段都有真实世界效果（雷雨、闪电、妖兽潮、粒子、声音），
  **不是一道闪电**（`Calamity.spec` 的 `effectKeys` 至少 2 个，审计要求）。
- **针对性有硬上限**：`CALAMITY_TARGETING_CAP = 0.45`。天意最多把 45% 的火力对准弱点，
  剩下的必须是无差别部分 —— 这是「不能无条件发动必杀」的可执行形式。
- **渡劫失败不抹杀**：失败只扣天道道痕与寿元，惩罚上限 `CALAMITY_MAX_FAIL_PENALTY`(0.35)。
- **玩家可以利用灾劫成长**：渡过即得道痕（`Run.profitable()`）。
  这与原著「灾劫是道痕最主要的增长途径」一致 —— 逃避灾劫 = 成长停滞。
- **发动有前提**：`Calamity.conditionsMet` 检查转数、仙窍稳定性、天道权限、意志预算；
  仙窍不稳（`<0.35`）时天劫以上**不允许发动**。
- **混沌不受支配**：`Calamity.chaosInfluenced()` 恒为 false。

### 3.6 仙道配套

| 组件 | 实现 | 原著锚点 |
|---|---|---|
| 三气升仙 | `Immortal.SanQi(tian, di, ren).harmony()`：三者越接近 1:1:1 成功率越高 | 升仙三气 |
| 师法自然 | `Ascension.observeNature(ticks)` 累积，上限 `SHIFA_ZIRAN_BONUS_CAP`(0.40) | 8 章 |
| 天道封锁 | 灾劫（`Calamity`）与寿蛊（`LifespanSupply`）各自独立承担；**3.13.0 起删除了 `Ascension.heavenLock`**，宿命不再是普通升仙的总开关 | 9 章 + 7 章 |
| 仙窍 | `Aperture`：等级 / 稳定性 / 仙元 / **内部时间倍率** / 内部资源账（**必须完整注册 ID**） | 8 章 |
| 独立仙窍 | `willIntrusionPossible(independent, hasHeavenDaoMark)`：独立仙窍是天意**管不了**的避风港；但内部若有**天道道痕**，天意仍会本地产生 | 1 章 + 7 章 |
| 寿蛊供给 | `LifespanSupply`：`influence(delta)` 改未来产出速率，`settle()` 结算**自然产出**（歉收时可能这一轮不成蛊）。**没有任何扣除库存的方法** | 9 章（英译，部分核实） |

### 3.7 宿命与星宿

- **宿命蛊世界唯一**：`DestinyGu` 挂在 `WillState`（SavedData，全维度共用一份），
  带 `worldId` 与 `matchesWorld()` 唯一性校验；实体化代次/保管版本/最近合法事务由
  `DestinyCustody` 记账（**物品 UUID 不是唯一性证明**）。
- **3.13.0 起是四阶段**（默认 `BODY_DAMAGED`，星宿合道影响仍在）：
  `BODY_DAMAGED`（本体受损，约束有缺口）→ `BODY_WHOLE`（本体完整，**只能由完成的修复事务产生**）
  → `BODY_DESTROYED_REVIVABLE`（本体被毁，仍有重现可能，不是最终结局）
  → `SPLIT_AND_DISTRIBUTED`（拆分并与运结合、分发众生，**只能由独立的后续炼制事务产生**）。
  摧毁与炼制分发是**两个独立事务**；载体丢失/迁移/运输只是保管状态，不混入阶段。
- **删掉了 `integrity=0.62` 与「0.95 即完整」**：数值若保留只是「修复任务进度」，
  不代表宿命强度，也不驱动阶段。
- **`fateLock()` 万能封锁系数已取消**：`@Deprecated` 恒返回 1.0，不参与任何判定。
  能不能做某件事改由 `DestinyRules` 按「阶段＋手段＋目标条件＋证据」给四态
  （允许/受限/条件不足/未实现）——**普通升仙与 MC 默认重生在任何阶段都允许**。
- **`heavenControl()` 按阶段直接给出**（0.85/1.00/0.75/0.60）：天意预算、感知与灾劫
  照旧工作，不会因为宿命重做被一起关掉。
- **星宿意志是第三方**：`StarWill` 有自己的目标（重修宿命/护天庭/压制天意/守星），
  有份额、会疲惫、**不能完全取缔天意**；它干涉天意，天意也能反过来压它（`willCounter`）。

### 3.8 反制：逐环生效，没有「免疫天意」

`will/Counter` 的映射**来自原文**，不是设计取舍（`docs/考据-天意能力清单.md` §4）：

| 手段 | 改变哪一环 | 原文依据 |
|---|---|---|
| 暗渡 | 感知 | 机制**原文未明说** → 只取最保守一层，并标记 `unreliable` |
| 神不知 | **只改推算** | 「任何的念头、意志、情感，都推测不出你的状态和来历」 |
| 天消意散 | **只改载体**（并损伤载体） | 「专门针对天意，能够将天意驱除干净」 |
| 炼道清除 | **只改载体** | 「先将春秋蝉升炼，再逆炼」 |
| 炼化天道道痕 | **只改载体**（治根） | 「治根之法便是直接炼化了这些天道道痕」 |
| 天机手段 | 推算 | 天机仙蛊牵引/预测 |
| 天外之魔（完整） | **只改宿命约束** | 「已经超脱限制」 |
| 天外之魔（半成品） | 宿命约束（35% 强度） | 「他还受到天意的影响和摆布」 |

三条硬边界（测试里反证）：

1. `Counter.immuneToCalamity(kind)` **恒为 false** —— 完整天外之魔照样吃灾劫伤害。
2. **神不知不产生感知盲区**：`coverTicks()==0`，天意照样看得见你，只是算不出你的来历。
3. **没有任何手段改变「天道控制」**，那一环只随宿命阶段变化。
4. 九转智道可以破神不知（`breakableBy`）。

## 四、春秋蝉：整个存档回到过去

### 4.1 能力边界（先说清楚）

| 能做 | 不能做 |
|---|---|
| 回到**已经生成并校验过**的快照节点 | 回到没保存过的时间点 |
| 还原区块、方块实体、容器、实体、玩家数据、`data/`、维度目录 | 抹除**现实中玩家已经知道的信息** |
| 分维度、全存档一致地还原 | 运行期零散覆盖区块文件（会毁档，禁止） |
| 施术者保留意志与记忆 | 把背包/资源/装备**额外**带回过去（会刷物品，禁止） |

### 4.2 两段式流程

```
[游戏内] /tianyi snapshot                 ← 落盘 + 复制 + 逐分区 SHA-256
         /tianyi rewind <id> confirm      ← 校验 → 写 pending_rewind.json → 受控停机
[服务器停止后]
         python _pack/rewind_apply.py --world "<存档目录>"
                                           ← 重算摘要比对 → 备份当前世界 → 交换 → 写完成标记
[重启]    服务端加载还原后的存档，新分支名记录在完成标记里
```

为什么不在运行期做：区块正在被读写，复制到一半的 `region/*.mca` 会造成
「半新半旧」，严重时整片地形异常甚至无法加载。所以**恢复必须等世界关闭**。

### 4.3 完整性校验

- 每个分区（`CHUNK`/`BLOCK_ENTITY`/`ENTITY`/`PLAYER`/`MOD_DATA`/`WORLD_STAGE`）
  算「按路径排序的 `relpath:sha256` 拼串再哈希」；`SnapshotService.requestRewind`
  **按磁盘重算**而不是信任元数据，不符即拒绝。
- 未通过校验的快照永远进不了 `Store.latest()`（只能回到验证过的节点）。
- 交换前把当前世界整体备份到 `tianyi_rewind_backup_<时间戳>/`，回溯本身也可回退。

### 4.4 天意是否获得未来信息

**不会，除非它通过春秋蝉参与了。** `History.willLearnsFromLogs()` 恒为 false ——
系统自己记的日志不算天意的情报。

## 五、命令（全部需要权限，普通玩家没有）

| 命令 | 权限 | 作用 |
|---|---|---|
| `/tianyi status` | OP(2) | 宿命阶段、天道权限、意志余量、载体/布局/灾劫/机缘计数 |

## 六、旧档迁移

`world/LegacyRetire.migrate(player)` 在登录时执行，**幂等**（`tianyi/meta/retired >= 3` 直接返回）：

- 归档子树：`econ`（天机/签到/摇命/账本）、`quest`（谕令/试炼）、`open`（天命词条）、
  `path`（道途）、`ai`、`shop`，以及旧版写在根上的 `tianji/signedDay/streak/pity/life`。
- **搬到 `tianyi/archive_v3` 而不是删除** —— 可回退。
- **不碰本体进度**：转数、寿元、道痕、蛊虫栏一概不动。
- **不强制死亡或转世**：旧「百世书」状态只归档，不触发转世。

世界侧状态（`tianyi_will` SavedData）自带 schema 号，未知枚举值跳过而不阻断加载
（跨版本旧档也能读）。

## 七、数值从哪来

**原著没有给任何数值。** 所有数值集中在 `will/WillConfig.java`，每条注释都标 `[平衡参数]`。
典型取值：失衡阈值 0.38、威胁下限 0.55、针对性上限 0.45、酝酿周期 6000~48000 刻、
仙窍内部时间 1~12 倍、寿蛊供给周期 30 游戏日。

审核时可以一眼区分「原著事实」（在 `docs/考据-天意能力清单.md`，带引文）
与「实现取舍」（在 `WillConfig`，带 `[平衡参数]`）。
