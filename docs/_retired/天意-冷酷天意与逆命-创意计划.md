## 0. 一句话体验

**天意提供帮助，同时借玩家的行为推进自己的目的；玩家通过积累真实情报，获得拒绝、质疑和反制天意的能力。**

冷酷天意的具体含义：它不说谎，但**隐瞒**。所有显示给你的数字（费用、期限、进度、奖励、处罚）都必须可靠；它不肯说的，界面显示「未知」，而不是编一个。

## 4. 数据结构（带版本号 + 幂等迁移）

```
tianyi/
├─ ledger/  (schema=2)         points lifetime earnDay earnedToday refundedTotal penaltyTotal
│                              once.<action>            ← 一次性结算标记
├─ sys/                        attention 计数（enlighten/defy/ban）、life、bestTianji、blessings
│                              rebirthPending / rebirthReason（待迁移标记）
├─ contract/ (预留，第二期)     每份命契：id kind target(dim/uuid/type) expireAtGameTime
│                              observations 完成态 违约记录
├─ evidence/ (预留，第三期)     观察到的事实、推演结论与事后事实的对应
├─ epoch/   (预留，第四期)      每一世独立标识，每世最多结算一次
└─ econ/ legacy                旧键保留，不删除（迁移来源，可回滚对账）
```

**迁移规则**：`schema < 2` 才搬；累计取新旧较大值；旧键一律不删；不反向扣任何本体数值。迁移幂等，重复执行结果不变。

## 5. 六项玩法（规格摘要）

### A. 限时命契（替代永久词条）

| 契约 | 内容 | 费用 | 权限 | 期限 |
|---|---|---|---|---|
| 借眼 | 读当前观察目标的真实兽类词条与已知风险 | 天机 | 只见已观测目标 | 服务端 gameTime |
| 借算 | 读资源与炼蛊/推算实际状态，列可验证准备条件与缺项 | 天机 | 只给缺项，不给配方 | 同上 |
| 借断 | 撤销或改选尚未结算的契约 | 天机 | 仅限未结算 | 即时 |

每份契约必备字段：费用、权限范围、绝对到期时间（主世界 gameTime）、限制、注视变化、失效条件。
**不用客户端隐藏按钮实现撤销**：效果由服务端按 `expireAt` 逐次校验，过期即失效。

### B. 顺命 / 逆命（围绕真实兽王，互斥）

- 顺命：击杀绑定目标。
- 逆命：近距离观察满时长，再脱离到安全距离，目标仍存活。
- 默认值（可配置）：观察距离 24 格、累计观察 60 秒、脱离 64 格、期限 1 游戏日。
- 目标绑定维度 + 实体 UUID + 类型 ID；档位用兽王名号（百/千/万/兽皇），**不按血量**。
- 只统计「目标已加载且存活、玩家在距离内」的时间；目标卸载/消失/被他人击杀一律记失败。
- **不为契约强制加载区块**。拒约无罚；接约后只能走一条路线，由状态机管。

### C. 基于证据的推演（替换"稳/险/必死"）

输出三段：**已观测事实** / **有依据的规则推断** / **未知因素**。
数据缺失显示「未知」，不折算成 0。禁止输出精确胜率或生死保证。
基础告警（压力临界、魂魄承载）免费；深入分析前先显示费用。推演**只读**，不写本体资源/物品/实体。

### D. 炼道问难

准备条件 → 实际尝试 → 记录结果 → 找缺项 → 解锁下一课题。
必须核对本体炼蛊的进度字段与成功结算（含是否存在 `== 100.0` 的精确判定，避免越过本体条件）。
成功必须由「真实尝试 + 状态变化 + 产物证据」三者关联；**拾取/丢下重拾/从箱子取出同名物品不算成功**。
失败留下研究记录但不重复给奖；奖励为天机、已验证知识、诊断权限，不产蛊虫材料。
兼容现有自动炼蛊；无法证明的配方条件显示未知。

### E. 情债与因果账

先做**只读桥接**：读 NPC 好感与关系阶段、任务完成记录（不写入、不生成好感）。
记录真实事件：好感阶段变化、任务完成、契约选择与明示机会成本、推演结论与事后事实的对应。
去重键 = 玩家 + NPC + 事件类别 + 本世标识。九道遗藏只接已确认的前置与分支，未取得的情报不泄露。

### F. 百世书

- 每世独立标识，**每世最多结算一次**（`settleOnce("life<n>.settle")`）。
- 继承：已验证的兽类与炼道知识、已识破的契约条款、天意行为历史、有上限的系统权限。
- 不继承：修为、道痕、资质、蛊虫；**不发放天机**（旧版按 30% 铸币已删除）。
- 转世识别：普通死亡/克隆/断线/转数下降都不算证据。无法确认时保持「待迁移」并禁用自动切换。

## 6. 界面（四页）

`命契 / 推演 / 因果 / 百世书`，沿用墨金几何风格（`fill` 绘制、全阴影文字、无贴图依赖）。

- 命契页：契约卡（费用·期限·进度·权限·失效条件），顺/逆两条路线二选一，借眼/借算/借断入口
- 推演页：三段输出（事实 / 推断 / 未知），费用前置提示，免费告警单独标出
- 因果页：情债账、契约选择与机会成本、推演命中/未命中、注视度与阶位
- 百世书页：本世编号、峰值、垂青、迁移状态（待迁移/已切换）

排版约束：全部文本可换行（`font.split`）、列表可滚动、按钮有禁用态、过期契约显示红字并不可再操作。

## 7. 网络与 AI

统一数据流：**本体快照 → 已验证事件 → 契约状态 → 服务端结算 → 客户端展示**。

- `tianyi:state` 只发只读快照与结算结果；`tianyi:action` 一律服务端校验 + 幂等；
- AI 只表达已确定内容（目标合法性、奖励、费用、期限、成败、迁移全由服务端规则决定）；
- AI 关闭/超时/报错/无密钥时，本地契约、推演、因果、结算**完整可用**；
- 密钥不进状态包、不进日志；`numen_api` 保持可选依赖隔离。

| 用例 | 期望 |
|---|---|
| 重复付款 / 退款 | 余额变化正确；**累计与当日已赚不变** |

### 2.9.3 · 一键构建（依赖自动提取，已实跑验证）

```bash
python _pack/build.py                 # 常规：复用 _pack/libs 缓存
python _pack/build.py --ephemeral     # 依赖只临时提取，构建后删除（工程不占 106 MB）
python _pack/build.py --bump 2.9.3    # 改版本后直接构建
python _pack/build.py --no-tests      # 跳过离线测试（不建议）
```

新增 `_pack/ensure_upstream.py`：从 10.20 本体壳里提取 `META-INF/jarjar/guzhenren-…jar`，
**校验 SHA256**（`b6d314d3…1fe2bc`），缓存命中则跳过解压；找不到壳或哈希不符直接失败，
绝不"凑合编译"。`_pack/build.py` 串起 **依赖 → 编译 → 离线测试 → 版本 → 打包 → 16 项审计**，
任一步失败即退出非 0，避免像以前那样漏跑某个审计。

实测（两种模式都跑过）：

| 模式 | 结果 |
|---|---|
| `build.py` | 依赖复用缓存 · 68 源文件 javac 0 错 · 测试 91 项 0 失败 · 审计 16 项全绿 · 产物 359,298 B |
