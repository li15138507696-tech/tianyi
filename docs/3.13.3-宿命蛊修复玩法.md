# 3.13.3 宿命蛊修复玩法

本版本增加一条玩家可参与的修复流程。它是模组玩法与资源平衡设计，不代表原著中的具体修复材料或步骤。

## 开始修复

1. 主手持有账本认可的正品，在铁砧、开裂铁砧或损坏铁砧前右键。
2. 每次投入蛊材元石 ×4 与紫水晶碎片 ×4，修复进度增加 25%。
3. 完成四次供料后，宿命蛊阶段转为完整，物品的赤红伤痕外观消失。

每次投入都会检查当前世界的正品凭证。空壳、过期凭证、复制品、隔离中的载体或材料不足都不会扣除材料。创造模式不扣材料；进度保存在世界数据中，其他玩家可以接着完成。

## 本次范围

- 使用现有世界唯一账本和 `repairProgress`，没有新增方块、物品、菜单或网络包。
- 监天塔、命败、毁坏后的重现与拆分分发仍未实现；相关来源不充分的玩法需要另行设计。
- 本次完成了源码编译和 JAR 结构检查，没有运行自动化测试或进游戏实测。
