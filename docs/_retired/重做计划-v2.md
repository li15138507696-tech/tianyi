> 依据：①四本系统流代表作的机制；②整合包权威知识库（`蛊真人整合包知识库_AI版.txt`，667 KB）；

## 一、先承认问题：我之前是「缝合」，而且缝的东西**整合包里本来就有**

| 我缝进来的 | 整合包/本体原生已有的 | 结论 |
|---|---|---|
| 天命·词条 147 条 + 凡人 20 体质 | 本体**十绝体**（开局可选、2000 道痕、压力自爆机制）、**资质/气运上限** | 重复且更弱 |
| 道途·流派熟练度 + 道痕 + 历练进度 | 本体**蛊修界面·流派页**（熟练度 0/101/501/1001）、**道痕页**、**叠血总表** | 纯重复 |
| 神之商店 907 件商品 + 限量/管理台 | 整合包**蛊材商店（K 键）**：购买/收购/每日 24 特惠/限时 3 倍收购/锻造神装 | 重复且更粗糙 |
| 天机点经济 | 本体**元石 + 元老蛊**、元石是唯一硬通货 | 发明了第二套货币 |

**所以正确做法不是「再融合一次」，而是把这三个子系统整个删掉，只做整合包真正缺的那一层：系统。**

## 二、四本系统文给了什么可复用的机制

| 作品 | 金手指机制 | 可迁移的设计点 |
|---|---|---|
| [大王饶命](https://baike.baidu.com/tashuo/browse/content?id=4ca32cfefeea6f053540f607) | 别人对你产生**怨气**→换点数，怨气越深点数越多 | **收益由「行为引发的情绪/因果」产生**，而不是「打怪数量」 |
| [最强反套路系统](https://baike.baidu.com/item/%E6%9C%80%E5%BC%BA%E5%8F%8D%E5%A5%97%E8%B7%AF%E7%B3%BB%E7%BB%9F/23673281) | **套路点**：反着来、装、打脸才有收益 | 奖励**反直觉行为**（正道/魔道两条路都有收益） |
| [学霸的黑科技系统](https://baike.baidu.com/item/%E5%AD%A6%E9%9C%B8%E7%9A%84%E9%BB%91%E7%A7%91%E6%8A%80%E7%B3%BB%E7%BB%9F/23219731) | 任务 → 科技点 → **主干/分支科技树** | **任务=唯一成长入口**，点数只解锁"能力/权限" |
| [我只想安静的做个苟道中人](https://m.toutiao.com/article/7683061492094173759/) | 苟住、稳健发育、面板提示风险 | **面板要给"危险预警"**，不是只给任务 |

四条共同骨架（所有系统文都一样）：

```
面板（只读状态） + 任务（主线/支线/日常）+ 结算（即时提示音）+ 兑换（点数换权限）+ 人格（吐槽或冷漠）
```

**蛊真人化之后**：系统 = 「**天意**」，冷漠、只算因果、不讲善恶；提示音不是"叮"，是**铜钟一声**（本体已有 `GUCHONG_CUIDONG_4` 蛊鸣音效）。

## 三、新系统：只保留一个进度值，且不碰整合包经济

### 3.1 唯一新数值：天机（Causality）

- **不叫"点数"，不做商店**（商店已删）。
- 天机 **只有一个用途**：涨「天意阶位」，阶位解锁**谕令档位**与**系统功能**。
- 来源（全部读本体/整合包真实数据，只读）：

| 行为 | 天机 | 依据（KB） |
|---|---|---|
| 杀兽（按 百兽/千兽/万兽/兽皇 分档） | 小 / 中 / 大 / 极大 | 6. 蛊兽图鉴 |
| 完成 NPC 任务（可重复 / 不可重复 / 系列） | 中 / 大 / 极大 | 8. NPC 任务链三类 |
| 流派境界提升（101/501/1001 门槛） | 中 | 15.1 |
| 击杀兽皇级 BOSS | 极大 | 12. 终局 18 BOSS |
| **道德值下沉到 -100 以下** | 额外加成（魔道补贴） | 1.13 道德值 + 缉捕事件 |
| **十绝体压力 ≥60** | 不给天机，反而**告警/扣天机** | 16.1 压力机制 |
| 死亡 / 寿元骤降 | 扣天机（因果反噬） | 1.4 寿元 |

→ **打怪不再是唯一来源**，这直接解决"原版内容太没难度/太单调"的问题，也符合「大王饶命」那套"行为产生收益"。

### 3.2 谕令四档（任务体系）

| 档 | 名字 | 内容来源（KB 章节） | 刷新 |
|---|---|---|---|
| **天谕** | 主线，9 章 | 九道遗藏 8 位 NPC（20）、兽皇终局 18 BOSS（12）、五转城镇声望阶梯（17） | 不可重复，本世一遍 |
| **地谕** | 支线 | NPC 任务链（8）、流派传承地牢（18）、蛊方/杀招推算（1.10） | 每世可重做 |
| **日课** | 日常 | 喂养/炼化/推算/杀兽/在线 | 每游戏日 |
| **禁谕** | 危险/魔道 | 道德值下调、兽皇单挑、十绝体压力压制、越阶击杀 | 每周 |

目标类型（引擎只认这些，**不发明新玩法**）：
`击杀蛊兽(按 tier)` / `完成NPC任务` / `达到流派境界` / `推算完成` / `炼蛊成功` / `道德值区间` / `声望等级` / `探索地牢` / `击杀指定BOSS` / `在线时长` / `修炼进度`。

### 3.3 系统功能（天机阶位解锁，不发物品）

| 阶 | 解锁 | 说明 |
|---|---|---|
| 凡 | 面板 + 日课 | 开局就有 |
| 灵 | **兽皇预警**：附近出现兽皇/兽王时提示 | 对应「苟道流」的风险提示 |
| 玄 | **十绝体压力告警**（≥50 报数、≥60 红字） | 16.1 |
| 地 | **重抽一次谕令** | 每日 1 次 |

> 全部是**信息/权限**，不改本体数值、不发物品、不加货币。这样既"像系统文"，又不破坏整合包平衡。

## 九、修仙界系统文调研后的修正（v3 增补）

### 9.1 又读了哪几本，各给了什么

| 作品 | 金手指 | 对本项目的价值 |
|---|---|---|
| [苟在初圣魔门当人材](https://m.kace.cc/yuedu/30428/)（鹤守月满池） | 异宝**「百世书」**：死后重开一世，可带回前世的**宝物/修为/寿命/天赋** | **转世流**：我们已有 `TianyiRebirth`，把它从「清数据」改成「带回来」 |
| [天道图书馆](https://book.qq.com/baike/3dyr9wrwx2opn)（横扫天涯） | **收录→发现缺陷→推演完善**；血脉/阵法/灵魂创伤皆可解析 | 接本体**推算**（KB 1.10）：做「天意指瑕」，不给你力量，给你信息 |
| [修真聊天群](https://m.sohu.com/a/981904577_122129349/)（圣骑士的传说） | 全是修仙者的**聊天群**，靠前辈指点 | 天意扮演「传讯」：信息型金手指，而非全知系统 |
| [我师兄实在太稳健了](https://m.sohu.com/a/981904577_122129349/)（言归正传） | **稳健流**：极致谨慎 + 风险评估 | 面板给**胜率三档**（稳/险/必死），把"苟"变成可操作信息 |
| [没钱修什么仙？](https://ngabbs.com/read.php?tid=44873388) | 资源流：穷修的极限经营 | 日课里加「低资源完成」类目标，贴合元石经济 |

### 9.2 由此产生四个新机制（都在 v2 骨架内，不推翻）

**① 转世 = 百世书（最强的长线钩子）**

- 死或寿元尽 → 天意结算 → **带走 N 项**（宝物 / 修为 / 寿命 / 天赋里选，N 由天意阶位决定）
- 面板多一页「前世」，记录第几世、带回了什么
- 落点：改造现有 `TianyiRebirth`，复用 `TianyiBoard` 做轮次账本；**只带系统侧与本体允许的东西**（气运/寿元小幅返还，绝不改转数）

**② 天意指瑕（接推算，最贴合蛊真人）**

- 本体推算要"拿念头点耐久"，纯手点、枯燥
- 天意收天机，**直接指出缺陷**：「此蛊方第 3 格应放 X」「此心得还差 12 点念头」
- 甚至**代算一次**（限额，每日 1 次）
- 优点：不膨胀数值、不改本体逻辑，只省时间——**系统文里最"对味"的一类金手指**

**③ 隐瞒条款（天意是反派，不是助手）**

- 蛊真人的天意**在利用你**，不是帮你
- 谕令有 `hiddenCost`：描述里**故意不写风险**，完成时才揭示（「代价：本世不得再用某道」）
- 「道」阶解锁**因果回溯**：事后能看到天意当时瞒了什么 → 形成"你越强，越看得懂它在骗你"的叙事
- 这是本项目与普通系统文最大的区别：**系统本身是压力源**

**④ 不设商店，改「垂青」**

- 学霸系统是「点数→科技树」，但商店要删
- 替代：**垂青**＝天意主动给的**一次性权限**（免死一次 / 免费复原一次推算 / 临时气运上限 +10）
- 触发条件写死（连续三日课、道德跌破阈值、单挑兽皇）→ **玩家不可购买**，只能被"赏"

### 9.3 如果只能做三件事

1. **天意指瑕**（接推算）——投入最小、体验提升最大、完全不破坏平衡
2. **转世成百世书**——把已有的 `TianyiRebirth` 从"清档"变成"爽点"
3. **隐瞒条款**——一句话成本，但让"天意"从皮肤变成角色

### 9.4 新增风险

| 风险 | 对策 |
|---|---|
| 隐瞒条款让玩家觉得被骗、骂人 | 保底：每道谕令必有基础奖励；隐瞒只影响"额外代价"，且可在面板「因果」页查"已瞒过你 N 次" |
| 天意指瑕被当成外挂 | 限额（每日 1 次代算）+ 只给"缺什么"不给"直接完成" |
| 转世带回太强，破坏本体平衡 | 只带天机/阶位/垂青次数 + 有限寿元，**不碰转数与熟练度** |
