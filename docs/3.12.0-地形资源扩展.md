# 3.12.0：按流派地形扩展资源点

> 版本 3.12.0。MC 1.21.1 / NeoForge 21.1.263 / Java 21。
> **未实机验证**：编译、离线测试、静态审计与真实 NBT 往返均已通过，但没有一条经过进游戏实测。

## 一、依据

扩展不是凭空加内容，而是照整合包权威知识库的两条既有规则：

1. §7.1 明确写着「**部分蛊材只在专属流派地形刷新，找材料先找地形**」，并列出 15 个流派地形。
2. §6.2/§6.3 给出蛊兽名录与各族分布地形。

已在本体 jar 内核实：这 15 个地形都是真实注册群系（`data/guzhenren/worldgen/biome/`），
下面用到的矿石方块、掉落表、守护兽实体也都在注册表中真实存在。

### 关于「转数威压」

知识库 §6.3 记载本体机制：玩家转数高出兽 2 转以上时，兽不会主动仇恨并会退开 16 格。
我们**不覆盖**这个机制，也没有加拴绳或瞬移追击。高转玩家因此可以绕过守护兽直接取物——
这是本体给的规则，正好支撑「可绕行、可偷采」。

## 四、地形门控怎么工作

1. 生成时先看候选位置的群系，再决定允许哪些模板（「先找地形，再找材料」）。
2. 群系不匹配 → 只跳过**这个候选**，不是停掉整个模板，也不是放宽白名单。
3. 蛊材生长地的群系白名单 = 原有 10 个原版温和群系 + 苍木林海 + 迷思幻林。
   原版那 10 个保持不变，所以**老存档里的生长地不会因这次扩展停止生长**。

## 五、配置

新增三个开关，均默认 `false`，且必须与 `oreEnabled` 同时为真才生效：

```toml
oreEnabled = true
yuanshiOutcropEnabled = true
chilianOutcropEnabled = true
wendingOutcropEnabled = true
```

## 七、已知边界

1. 若某个 guzhenren 群系在实际世界中不生成，对应的矿石露头就永远不会出现——这是保守的失败方式，不会替代成别的资源。
2. 元石露头的「地下」形态尚未实现，生成器仍只按地表高度找点。
3. guzhenren 群系的表层若不是原版土壤，蛊材在其中会因土壤判定失败而不生成。
4. 旧存档里已存在的站点不受新地形白名单影响（不回改）。
