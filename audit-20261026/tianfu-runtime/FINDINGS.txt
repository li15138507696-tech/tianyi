Read-only audit of tianfu 1.3.4 runtime. Original project and game directories unchanged.

Confirmed fixes in runtime-fixes.patch (five source files):
1. TianfuEffects: apply signed GU_CD aggregation while cd>0, so v2_gu_cd_ningse's -0.10 is enforced.
2. TianfuEffects: remove/re-add CHENMO before shortening duration, preserving amplifier/ambient/visible/icon.
   Installed 1.21.1 MobEffectInstance.update only replaces equal-amplifier duration when it is longer.
3. TianfuSlay: allow shiyuan_zhixing through the death reward gate without requiring slay/tuntian.
4. TianfuEffects / NeoForge1211Adapter: invoke existing maintainV2 from tick and sync actual field corrections.
5. NeoForge1211Adapter: lower the persistent lifespan ceiling when lifespan naturally falls, preventing recovery.
6. TianfuCombat / TianfuEvents: copy undying's top-level cooldown during confirmed-player clones.
   Installed NeoForge ServerPlayer.restoreFrom only automatically copies PlayerPersisted before firing Clone;
   TianfuOpening only copies the tianfu root, so this separate top-level long was being lost.
7. TianfuEvents: forget Combat's counter/adaptive runtime memory on death and every clone (including End returns),
   preventing newEntity.tickCount-oldEntity.tickCount<0 from prolonging the counter bonus indefinitely.
   A wiped reincarnation does not inherit the old undying cooldown.

Evidence:
- compile-result.txt: all 5 patched files compile against the installed runtime and original 1.3.4 jar, javac exit 0.
- regression-original.txt / regression-patched.txt: 16 Java cases; original reproduces failures, patched passes.
  Actual TianfuSlay and NeoForge1211Adapter classes are compiled unchanged except their proposed patches.
  GU_CD, silence, tick tail and maintainV2 execute extracted real source blocks with narrow Java test doubles.
- clone-regression-original.txt / clone-regression-patched.txt: 8 Java lifecycle cases; original reproduces
  lost cooldown and stale counter memory; patched passes ordinary death, End return and wiped-new-life cases.
  Actual TianfuEvents and extracted real TianfuOpening/Combat methods execute against narrow doubles.
- MobEffectInstance.javap.txt / ServerPlayer.javap.txt: installed dependency bytecode supporting the two contracts.

This is offline compile/control-flow validation, not an in-game integration test. No version change or install.
make_patch.py regenerates source copies and both patches. lifecycle-fixes.patch only contains the two
later lifecycle files for a parent integrator who already applied the first three files.
