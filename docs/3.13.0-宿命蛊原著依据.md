## 二、《命败》原文依据（逐条）

来源：https://www.sobqg.com/read/guzhenren/18154714.html

1. **外观**：「宿命蛊，形如蜘蛛，黑白两色，原本气息微弱，有着一道赤红伤痕，几乎要将它切成两半。这是红莲魔尊所造成的伤害。」
   → 宿命蛊 = 黑白蜘蛛；**受损形态有赤红伤痕**；伤痕来自红莲魔尊。
   模组映射：物品外观为黑白蜘蛛，受损时呈现赤红伤痕（贴图/名称后缀），**不新建第二套外观体系**。

2. **修复是完成事件**：「赤红的伤痕已然消失无踪，完好无损的宿命蛊，静静地趴着，气息健康洋溢。」「如今我天庭已彻底修复了九转宿命蛊」
   → 完整只由**彻底修复完成**产生。
   模组映射：`BODY_WHOLE` 只能由修复完成事务写入，**没有 0.95 阈值**。

3. **修复的代价是真实牺牲**：龙公「不惜生命，催动龙御上宾杀招」；「他的龙角已经折断，披头散发，浑身浴血」「寿命将尽」「连一丝魂魄都不存留」；「不只是我，而是多亏了诸位同道啊！所有的牺牲，都是值得的。」
   → 修复需要**真实消耗与多位参与者**，不是单人点一下进度条。
   模组映射：修复链要求真实资源消耗 + 主持过程，可被争夺中断。

4. **监天塔是设施，命败是杀招，二者都区别于实物**：「这座五域赫赫有名的仙蛊屋，如今是真正的九转仙蛊屋」「仙道杀招——命败」「这是货真价实的九转杀招！命中注定的攻击，无法躲闪」
   → 监天塔 = 仙蛊屋设施；命败 = 九转杀招；**持有宿命蛊 ≠ 能用命败**。
   模组映射：命败必须校验「设施成立 + 宿命核心接入 + 操纵者条件」，**不做成持有物品右键技能**。

5. **设施强度依赖宿命蛊作核心**：「拥有宿命蛊的监天塔，必然是当今世上第一的仙蛊屋」
   → 核心被夺/本体被毁后，设施能力应按条件失效。
   模组映射：核心有效性参与命败判定；失效即返回条件不足。

## 三、摧毁与分发的区分依据

仓库既有考据 `docs/考据-天意能力清单.md`（2026-10-24 抓取，逐字摘录）：

- 「因为你是天外之魔，只有天外之魔，才有可能改变过去。……红莲魔尊努力了一辈子，也只是打坏了宿命蛊，却无法破坏它。」
  → **「打坏」≠「破坏」**；且**只有天外之魔**才可能真正改变。这是「摧毁需完整天外之魔资格」的原文依据。
- 「宿命蛊编织丝网，叫做万般网。世间的万事万物，都在这片网中，受到宿命的摆布和操控。」
  → 宿命蛊 = 约束网络；摧毁后约束网络出现缺口，但不是「分发」。
- 「只要宿命蛊在，天庭就会轻易重建起来。因为星宿意志一直在影响着天意，宿命蛊中始终是人族当兴」
  → 宿命与星宿意志耦合；星宿影响单独建模，不与实物合并。

**待核验**：《毁了又如何？》《大时代！》两章原文未取到。因此：
- 「本体被毁后仍可能重新出现」——按规范与「打坏≠破坏」保守建模为 `BODY_DESTROYED_REVIVABLE`，**不设**任何天数刷新/定时重生的具体数值；
- 「拆分并与运结合、分发众生」——建模为独立阶段 `SPLIT_AND_DISTRIBUTED`，**必须由独立完成事件**产生，当前**未实现**（`NOT_IMPLEMENTED`）；
- 两者**不合成为一次 DESTROYED 事件**。

## 五、3.13.3 模组玩法扩展（非原著复刻）

3.13.3 增加铁砧修复循环：持有世界账本认可的正品时，每次消耗蛊材元石 ×4 与紫水晶碎片 ×4，推进 25%；四次完成后阶段进入 `BODY_WHOLE` 并清除受损外观。材料、铁砧交互和四段节奏是本模组的玩法/平衡选择，**不宣称来自原著**。修复使用既有 `repairProgress` 与 `completeRepair`，没有改变“只有完成事务才能转为完整”的阶段约束。
