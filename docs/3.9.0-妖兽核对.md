## 选择与验证

`EncounterBeasts.all()` 返回不可变白名单；`select(rank, seed)` 在满足准入门槛的项目中按种子确定性选一只。rank≤0固定灰狼；rank1只有灰狼/土狼；rank≥2可选六种。第一次遭遇固定灰狼由服务端调用方实现，后续使用此选择器。

独立 Java 测试 `EncounterBeastsTest` 检查白名单、重复ID、不可变性、边界种子、负境界回退、逐境界门槛、同种子一致性，以及1000个种子覆盖所有可选项。该测试不声称替代游戏内AI与战斗实测。
