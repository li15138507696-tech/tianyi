# 天意机缘：轻量可玩版

本文记录 3.9.0 的机缘设计（历史文档）。Minecraft 1.21.1 / NeoForge / Java 21，严格沿用提供的10.20本体。未自动安装，旧包保留；当前最新产物见 `docs/天意-介绍.md`。

## 玩家操作

1. 生存模式累计在线约一分钟，附近已加载的安全空地出现微光木桶。按 **J → 观象 → 当前机缘** 看方位、水平距离和下一步。没有安全位置时每十秒重试，不强制加载区块。
2. 本人在木桶四格内右键调查，直接得到 **32本体元石**；背包放不下的部分掉在本人脚边。奖励不装在木桶里。
3. 可直接点 **见好就收**。也可看清妖兽和完整规则后点 **押注挑战**，确认支付32元石。和平难度、余额不足、落点不合法或妖兽生成失败均不开战、不扣款。
4. 妖兽成功出现后计时180秒。允许朋友帮打；妖兽死亡时持有人必须存活、处于生存模式，并在机缘中心32格内。
5. 首个灰狼挑战成功返还32押金、额外128元石、迅捷I120秒；妖兽原生掉落照常。失败失去押金，当前真元减半，虚弱I60秒。
6. 完成后生存模式再累计在线8–12分钟，产生下一次机缘。死亡界面、离线和其他模式不推进冷却。

失败条件：超时、死亡、普通退出、切维度、离开生存模式、主动认输，或距中心超过64格持续五秒。死亡处罚复活后结算一次；正常停服暂停计时，重启继续。目标持续十秒无法恢复时取消挑战，仅退押金，不发额外奖励或处罚。

## 新增妖兽

只使用实际注册的本体实体，不凭名称创造属性。首次固定灰狼，后续按玩家本体转数开放随机池：未入门仅灰狼；一转增加土狼；二转及以上增加熊、红熊、灰熊、电狼。每次只出现一只。

六种ID、原生属性、词条风险与生命周期依据见 [妖兽核对](3.9.0-妖兽核对.md)。准入门槛是本附属的玩法限制，不代表兽王规模或妖兽实际转数。二转准入的四种较强妖兽额外奖励为基础配置的两倍，默认256元石；押注前面板显示实际金额。虎、豪电狼等会破坏方块或带复杂技能的妖兽暂不自动投放。

## 实现与边界

- `encounter/EncounterRun` 是状态机，`world/EncounterState` 将玩家ID、事件ID、地点、妖兽UUID、计时、押注与结算标记存进世界 SavedData。调查、扣款和胜负均有状态保护；重复点击不能再次领奖。
- `world/EncounterService` 负责合法落点、原生生成初始化、完整体型碰撞检查、本人距离、真实货币、真元同步、实体清理。客户端只提交动作与事件ID。
- `EncounterSyncPayload` 只向本人下发已公开的机缘，不同步后台评分、隐藏坐标、NPC总账。查询请求限流，未知动作与非法字段拒收。
- 每只挑战妖兽独立标记，不计逆天行为、宿命损伤和自然兽群数量。失败清理本事件实体；卸载实体再次加载时核对事件，已结束的实体直接移除，不强制加载。
- 木桶损毁且所在位置已加载时，未开战机缘安全结束，已得元石保留；未调查不会补发。直接破坏木桶的玩家操作会被拦截为调查，不能反复拆取奖励。
- 旧后台自动压制、布局推进和诱饵雷击默认暂停，保留代码与数据；不修改本体现有修炼进度。原有其他系统未在本次全面重构。
- 正常保存/重启有持久化保护；未实现跨世界与玩家文件的事务式断电恢复，不承诺任意进程崩溃零回滚。

## 参数

世界目录 `serverconfig/tianyi-encounters-server.toml`：`enabled`、`legacyAutomaticPressure`、`firstEncounterSeconds`、`minimumCooldownSeconds`、`maximumCooldownSeconds`、`baseYuanshi`、`stakeYuanshi`、`bonusYuanshi`。默认分别为 true、false、60、480、720、32、32、128。

战斗180秒、离场64格/5秒、成功距离32格、迅捷120秒、虚弱60秒、真元保留50%集中在机缘服务与设置类，首版固定，面板同步实际货币数值。参数调整只影响新产生的机缘，已有事件保留其金额快照。
