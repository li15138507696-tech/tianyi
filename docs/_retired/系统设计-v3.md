## 一、核心循环（把五个机制串成一个闭环）

```
                    ┌──────────────── 一世 ────────────────┐
                    │                                      │
  杀兽/做NPC任务/推算/道德 ──→ 天机 ──→ 天意阶位 ──→ 解锁谕令档位
                    │                    │                 │
                    │                    ├─→ 天意指瑕（推算加速）
                    │                    ├─→ 天意演算（预演）
                    │                    └─→ 垂青（一次性权限）
                    │                                      │
                    └──────── 死/寿元尽 ─→ 百世书结算 ───────┘
                                              │
                                     带回 N 项 → 下一世起点更高
```

**闭环的关键一环是"注视度"**（见 §4.5）：演算越多 → 天意越盯你 → 禁谕与风险越高。
这让玩家在"用系统"和"被系统用"之间反复权衡——这是本设计最不像普通系统文的地方。

### 2.2 为什么不给"点数换物品"

商店已删、元石是本体硬通货。天机**只做两件事**：涨阶位、付费使用系统功能（指瑕/演算/重抽）。
→ 结构上不可能出现"天机贬值"或"经济双轨"。

## 四、六个机制详规

### 4.1 谕令四档（生成器）

```
模板 × KB 数据 × 难度参数 → 谕令 {标题, 描述, 目标, 天机, 隐藏代价?, kbRef}
```

- **天谕**（主线 9 章，不可重复）：每章固定 3 条，全部指向 KB 的具体内容（见 §7）
- **地谕**（支线，每世可重做）：从 KB 8 的 NPC 链 / 18 地牢 / 推算 里抽 3 条
- **日课**（每游戏日 3 条）：喂养、炼化、推算、杀兽、在线、走访
- **禁谕**（每周 1 条，阶 ≥5）：道德下沉、越阶击杀、单挑兽皇、压十绝体压力

生成器不能凭空造目标：**每个目标类型都必须在 `TianyiObjective` 的白名单里**，且带 `kbRef` 章节号（审计强制）。

### 4.2 天意指瑕（接本体推算）

- 本体：推算界面拿念头点耐久，纯手点（KB 1.10）
- 天意：花 **5 天机**，直接指出"缺什么/哪格错"；阶 ≥5 可**代算**（一次性补满，每日 1 次）
- 只读推算物品的 NBT（耐久/材料），**不写**耐久以外的任何东西；代算写入耐久 = 与本体一致的操作
- 收益：把最枯燥的几十次点击变成一次决策

### 4.3 天意演算（模拟器流）

- 阶 ≥4 解锁；**每日免费 1 次**，额外每次 **15 天机**
- 预演一次行动（打兽皇 / 进地牢 / 推算），给三档结果：稳 / 险 / 必死 + 一句原因
- 演算**不改变现实**（不能靠演算拿奖励），只出信息
- 演算次数 → 累积「注视度」（§4.5）

### 4.4 隐瞒条款 + 因果账本

- 谕令可带 `hiddenCost`（例：「代价：本世不得再用某道」/「代价：气运 -5」）
- 描述里**不写**，完成时揭示
- 阶 ≥6「因果回溯」可查：`已瞒你 N 次 / 被注视 K 次`
- 保底：**基础奖励永不隐藏**，只有额外代价隐藏

### 4.5 注视度（本设计的核心张力）

```
注视度 = floor(演算次数 × 2 + 违背天意次数 × 5 + 禁谕完成数 × 3)
```

| 注视度 | 效果 |
|---|---|
| 0–9 | 无事 |
| 10–24 | 禁谕频率 ×2；兽皇刷新半径 +8 格 |
| 25–49 | 天意低语变刻薄；隐藏代价概率 50% |
| 50+ | 开启「天意垂钓」：随机在你附近降一条**极难**的禁谕，拒做则扣 20 天机 |

→ 玩家必须权衡"多算几次"与"被盯上"。**用系统的代价，是被系统看见**。

### 4.6 两道（证道 / 求道）

借用《玄鉴仙族》的「证金 vs 求金」二分（[参考](https://book.qq.com/book-read/60206384/53)）：

| | 证道（正） | 求道（魔） |
|---|---|---|
| 做法 | 完成天谕/地谕，道德 ≥0 | 完成禁谕，道德 <0 |
| 天机 | 慢但稳（×1.0） | 快（×1.5） |
| 注视度 | 低 | 高（×2） |
| 风险 | 无 | 正道缉捕（KB 1.13）、天意垂钓 |
| 天意口吻 | 「你还算听话」 | 「你终于像个人了」 |

两道**可随时切换**，但切换时清空本世该道的加成（防两头吃）。

## 五、转世 = 百世书

死 / 寿元尽 → 结算：

1. 记录本世到 `TianyiBoard`（第几世、天机峰值、击杀兽皇数、瞒过几次）
2. **带回 N 项**（N = 1 + 阶位≥7 时 +1，上限 3）：从【天机 30% / 一份阶位经验 / 一次垂青 / 3 点寿元 / 一条道位】里选
3. **绝不带**：转数、熟练度、道痕、蛊虫（本体的归本体）
4. 阶 ≥8 可保留一条「道位」：某流派下一次谕令 +50% 天机

面板新增「前世」页：第几世、带回什么、最高注视度。

### 6.3 文案风格（天意人格）

- 短句。不用感叹号。不用"恭喜"。不解释。
- 例：

  - 完成：「你还活着。天意记下了。」
  - 演算：「你看到自己死了三次。」
  - 隐瞒揭示：「代价：本世不得再用剑道。」

## 八、AI 降谕怎么接（复用已有能力，不重造）

已有：Numen 工具 / 自定义接口 / DSH 凭据三条通路。
新用途：**AI 只写文案，不写数值**。

- 服务端把「谕令模板 ID + KB 片段」丢给 AI → AI 返回 `{标题, 描述, 低语}`
- 目标、数量、天机、隐藏代价**全部由模板与服务端决定**
- 失败就退回本地文案池（每档 12 条，手写）

→ 这样 AI 的价值从"编任务"（不可控）变成"编味道"（可控且好看）。

## 十二、风险与取舍

| 风险 | 取舍 |
|---|---|
| 删 3 万行后功能骤减，玩家觉得"少了什么" | 用天谕 9 章 + 四档谕令补量；且删掉的是**重复品** |
| 注视度机制可能让小号/新手被压死 | 注视度只在高阶（≥4 阶）才计入，且 50+ 的垂钓可拒做 |
| 隐瞒条款可能招骂 | 基础奖励永不隐藏 + 因果页可查 |
| 演算可能被当成"作弊器" | 只出三档结论，不给具体数值；每日 1 次免费 |
| 天意指瑕可能破坏推算玩法 | 只给"缺什么"，不给"直接完成"（除 5 阶每日 1 次） |
