# 墨金卷册界面

版本：3.8.4（历史文档）。本文记录该版本的设计；当时产物见版本记录，当前最新产物见 `docs/天意-介绍.md`。

保留原有玩家知识记录和服务端动作，本次重做原生游戏界面，不恢复积分、商城或百世书。

## 使用

- J 打开，Esc 或右上角关闭；按键仍可在设置中更改。输入查阅文字时，J 正常作为文字输入。
- 观象、察局、藏识、行藏四卷保留。列表按记录时间倒序，展示来源、时日与存疑/陈旧标记。
- 输入框按当前卷的标题、正文、疑局名称和来源查找；“收藏”按钮筛选已收藏条目。Ctrl+F 聚焦输入。
- 宽窗口同时显示目录、列表和正文；小窗口点条目进入正文，通过“返回卷目”返回列表。
- 列表与正文分别响应所在区域的滚轮，滚动条可拖动；方向键选择条目，Enter 在小窗展开，PageUp/PageDown 翻阅。
- 收藏、存疑、疑局归类继续由服务端验证和保存。等待回包时暂时禁用重复批注按钮。
- 没有记录就显示真实空状态；筛选无结果有单独提示。不加入预置见闻。

## 绘制与边界

原生 GUI 像素绘制、一次边饰，不平铺带框素材，不缩放整个面板，不启用背景模糊。
正文按实际字体宽度换行，使用裁剪区和独立滚动条，按钮不覆盖正文。页签、搜索和回包更新后，选中内容只能来自当前可见列表。

仍仅显示服务端已下发的数据。协议只有记录时间与最后核实时间，因此界面没有伪造一个独立的“事件发生时间”。
察局展示服务端提供的缺失条件，不把手动归类解释为证明了天意布局。后台秘密、威胁与预算均不进入界面。

## 验证结果与方式

本轮真实依赖编译 63 个源文件成功；六组离线测试通过（共 887 项断言），界面适配器 50 项交互检查通过，七项构建审计通过。
新包 432,391 字节。Java JarFile 清单解析与 URLClassLoader 读取均通过。

- `_pack/run_tests.py`：原有行为测试，加纯 Java 响应式布局、区域命中和滚动边界测试。
- `_pack/ui_preview/check_ui.py`：用隔离的绘制适配器运行实际 Screen 源码，检查切页、搜索、动作目标、独立滚动、小窗返回和空记录；生成四张标注清楚的布局预览。
- `_pack/build.py`：真实 Minecraft/NeoForge API 编译、离线测试、打包与七项审计。

预览位于 `_pack/ui_preview/`：wide.png、compact-list.png、compact-detail.png、empty.png。
其中的记录只属于测试夹具，不打进游戏内容、不写入玩家存档。预览使用替代字体，不能视为 Minecraft 实机截图。
