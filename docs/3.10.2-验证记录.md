## 发现与小修

### D-01：非字符串可空字段被静默转换，破坏坏行原样隔离（已修，回归待运行）

- 文件：`src/main/java/net/guzhenren/tianyi/world/EncounterState.java`。
- 触发：有效行的 warning/message 改为 IntTag，或 WAITING 行允许空值的 id 改为 IntTag。原实现遍历键直接调用 `row.getString(key)`；错误类型变为空串，restore 对这些字段允许空串，因此错误行不会进入隔离。
- 后果：保存时写成 StringTag 空串，原 NBT 类型和值丢失，不满足坏行整账隔离及证据保留承诺。现有错误列表元素类型测试未覆盖这种字段级错误。
- 修复：在原有 try/catch 内先对每个行字段检查 `Tag.TAG_STRING`，再读取字符串；非字符串直接进入既有整账隔离分支，保留根 NBT，并清空已加载行。未改变 schema、ID、正常快照或奖励逻辑。
- 回归：`_pack/probes/EncounterPersistenceProbe.java` 增加 non-string warning、message 和 WAITING id 三例；各例复用 preserved，检查停止新建/读取玩家账、原结构相等、压缩 roundtrip 后仍相等。D 未运行这些新增用例。

## 静态审查结论及边界

- EncounterState 对未知 schema、坏列表、重复 owner、restore 失败整账保存原始副本；隔离时 tick、sync、交互、实体 join 均有保护，不向空 EncounterRun 解引用；无自动奖励/处罚/清理隔离目标的路径。
- 调查及胜利先标幂等状态并 dirty 后给物品；处罚先 consumePenalty 并 dirty；生成先 addFreshEntity 且确认仍活着/未移除，再扣款及 startBattle。缺失/卸载实体不再凭缺失退款。关闭玩法后 tick、死亡、退出、复活处罚及切维度处罚均被入口阻止。
- WorldSites 创建、靠近产出、物流与 WillServer 的旧拾取归属均受独立默认 false 的 legacyAutomaticResources 控制；普通猎兽及拾取路径未见新增误处罚调用。保留存量和在途批次，不扩展有限资源功能。
- JournalNet pending 在服务端 tick 重试、时钟使用主世界；JournalStore.load 按当前 ServerPlayer 的 persistent data 读取，发送目标为同一玩家。静态审查未发现此次改动把世界总账或他人见闻下发的路径；这不等同于双客户端实测通过。
- SavedData、玩家物品及实体无跨文件事务；dirty 不等于磁盘提交。硬崩溃任意时点下仍不能保证绝不丢失或重放。第三方生成/死亡事件取消、异常、满背包落物拒绝、真实退出重连/切维度及客户端渲染仍未实机验证。
- 已读范围内除 D-01 外，未确认新的 NPE、复制、误处罚、隔离数据丢失或同步泄密缺陷；不是对所有兼容组合的完备证明。
